TEST REPOSITORY - TEST DATA ONLY

Every document in this folder is test data for the search MVP.
Most of it is invented (synthetic). The public-fhwa/ folder holds two
real, public FHWA documents; see public-fhwa/SOURCES.txt.
None of it is project data. Do not use any value for design,
construction, approval or safety decisions.

This folder stands in for the company's existing document repository.
The search service indexes every file that has a reader (.md, .pdf, .csv,
.xlsx, .dxf). The .txt and .jt files have no reader; the coverage report lists them.

Layout
  project-cedar/      10 short Markdown load reviews. Used for permission tests.
  specifications/     3 Markdown specifications, including a table and a
                      draft that conflicts with an approved value.
  project-riverside/  Footbridge load rating report (PDF, 3 pages).
  project-northgate/  Warehouse structural calculations (PDF, 4 pages).
  registers/          Material approval register (PDF, 2 pages) and a
                      cross-project component register (CSV, rows for
                      Harbour, Cedar and Riverside).
  project-harbour/    Structured data: a component schedule (CSV), a roof
                      schedule (XLSX, JP and Maya only, one formula with no
                      cached value), a design basis with Markdown tables,
                      a scanned PDF with no text layer, a DXF drawing whose
                      title block holds a safe working load and an approval
                      status, and two .jt files that are NOT valid JT files
                      (cad/FIXTURES.md).
  public-fhwa/        Two real FHWA steel bridge handbook volumes
                      (PDF, 25 and 172 pages). See SOURCES.txt.
  generated-projects/ 120 short generated Markdown project files. They make
                      the repository larger than 100 documents, as the use
                      case requires, and compete with the real answers.

In total: 149 files, 145 with a reader.

The synthetic PDFs are generated by scripts/make_test_pdfs.py, the
generated projects by scripts/seed_demo.py, and the structured fixtures
(project-harbour/, registers/component-register.csv) by
scripts/make_structured_fixtures.py, and the DXF drawing by scripts/make_cad_fixture.py. Edit a script and run it again
rather than editing its output by hand.
