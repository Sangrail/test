Proof of concept, not production security.

This MVP has no real sign-in: anyone can pick any demo user, to see that the same question gives different answers to people with different permissions.

In production there is no user picker. Each person signs in through the company’s identity provider, and the permissions of the repository that holds the files decide what that authenticated user may see. A user sees only the documents they are entitled to, and never the names of projects they are not.
